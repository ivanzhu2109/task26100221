# task26100221

DataForge 增量 SimHash 去重索引（Go 库，包名 `dataforge`）。

## 功能

输入记录为 `(id uint64, fingerprint uint64)`，采集与指纹计算由上游完成。
两条记录的指纹汉明距离 ≤ 3 时存在边，簇即该无向图的连通分量；每簇代表
为簇内最小 id。单线程调用，不涉及持久化。

```go
ix := dataforge.New()
ix.Add(id, fingerprint)          // 返回时本次插入引起的簇合并已生效
rep, ok := ix.Lookup(id)         // 当前所属簇的代表 id（实时，非缓存）
groups := ix.Groups()            // map[代表id][]成员id，每个 id 恰好出现一次
```

## 设计

- **候选生成（4 波段索引）**：比特位 `p` 划入波段 `p&3`，每个波段 16 个
  交错比特。由鸽巢原理，汉明距离 ≤ 3 的两个指纹至少有一个波段完全相同，
  因此「波段碰撞候选 + 精确距离过滤」是完备的，无抽样、无概率漏检、无
  候选数量上限。比特交错使高低 32 位都参与每个波段键，避免「高 32 位
  相同」的数据集退化为全量候选。
- **簇维护**：对不同指纹槽位做并查集，根节点维护簇内最小 id；`Add` 只
  对候选做精确距离比较并按需合并，`Lookup` 实时查询当前根的代表。
- **重复指纹**：命中已有指纹时走快速路径，只做 O(1) 的代表更新，距离
  计算量不随重复记录数增长。
- 候选比较针对全部历史指纹（不限于簇代表），非代表成员上的连接同样
  生效；不扫描全部历史、不做全量两两比较、不建距离矩阵。

## 测试

```sh
go test ./...                      # 全部测试
go test -run TestLargeScale -v .   # 单独运行大规模测试（固定种子 26100221）
go test -short ./...               # 跳过大规模测试
```

- `TestRequiredSequence` / `TestInsertionOrderInvariance`：题目指定的
  4 条记录序列（新桥与第一簇旧代表距离为 6，连接发生在非代表成员上），
  以及全部 24 种插入顺序下分组与代表一致。
- `TestAgainstReference`：与 O(n²) 穷举参考实现逐次 Add 后比对完整分组
  与全部 Lookup；样本含距离恰为 3/4、最高位不同、重复指纹与多跳大簇
  （特征计数由断言保证非零）。
- `TestLargeScale`：20 万均匀不同指纹 + 10 万高 32 位相同指纹 + 10 万
  复用同一指纹的记录，固定种子打乱后逐条 Add，校验每个 id 恰好出现
  一次、每簇代表为最小 id、重复指纹记录归属一致。

## 容量测试结果（本机 Apple Silicon，Go 1.27）

- Add 阶段 40 万条记录总耗时约 **0.5 s**（预算 60 s）
- Add 阶段峰值堆内存约 **78 MiB**（预算 256 MiB）
- 产生 293 728 个簇；10 万条重复指纹记录与指纹属主同簇（簇大小 100 001）
